Feature 2.4 — the browser platform

The interfaces of the plan's §5.2 in a browser: a folder read and written in place through the File System Access API, a read-only snapshot whose Save downloads, the vendored Examples workspace, settings in localStorage, drafts and remembered handles in IndexedDB. The browser layer drives it through window.platformProbe; the page runs nothing on its own. It is built for the suite alone and is no part of the deployed application.
